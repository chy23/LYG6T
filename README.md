# 新北市林口區麗園國民小學 115學年度六年級戶外教育參觀活動 電子手冊網站

🎒 本專案為新北市林口區麗園國小六年級戶外教育（畢業旅行）量身打造的行動友善電子閱覽網站。

## 🌟 網站特色

- 📱 **智慧互動導覽模式**：專為智慧型手機與行動裝置打造，適合學生與家長在旅途中即時查閱。
- 📑 **原書高清翻頁閱覽**：高解析度 1～24 頁手冊原樣電子翻閱，支援單頁/雙頁開本切換與原版 PDF 下載。
- 🏷️ **學生個人數位證件卡**：姓名、班級、房號（今埔里/麗寶福容）、車號與桌號本地儲存與列印。
- ⏳ **出發倒數計時**：精準倒數至民國 115 年 11 月 25 日 06:30 集合出發。
- 📅 **三天兩夜時程表**：清楚標記行程與服裝規定（D1便服、D2班服、D3運動服）。
- 🎒 **行李打包選取表**：隨身背包與行李箱分類打勾、即時進度條、自訂物品新增與減塑宣導。
- 🗺️ **四大景點深度導覽**：921地震教育園區（五大展館）、車埕林班道、鹿港老街、麗寶樂園探索世界。
- ✍️ **線上互動學習單**：921地震學習單、鹿港古蹟配對題、麗寶樂園10題知識庫，具備即時批改、得分與解答回饋。
- 🛡️ **生活安全與急救常識**：乘車安全、住宿安全、冷氣溫度建議、燙傷/出血/扭傷處理，以及醫療輔助法規說明。
- 📞 **緊急聯絡簿與導航**：學校、旅行社、今埔里飯店、麗寶福容飯店一鍵撥號與 Google 地圖導航。
- 🎨 **旅途回憶塗鴉板**：手指手繪塗鴉、多色調色盤、一鍵下載 PNG，與同學祝福留言牆。
- 🔍 **全站全文即時搜尋**：快速鍵 `/` 快速檢索手冊關鍵字。

## 🚀 如何啟用 GitHub Pages 線上瀏覽

1. 前往本 GitHub 儲存庫的 **Settings**（設定）頁面。
2. 點擊左側選單的 **Pages**。
3. 在 **Build and deployment** 下方的 **Branch** 選擇 `main` 分支，資料夾選擇 `/ (root)`。
4. 點擊 **Save**（儲存），幾分鐘後即可透過專屬網址線上瀏覽：
   `https://chy23.github.io/LYG6T/`
